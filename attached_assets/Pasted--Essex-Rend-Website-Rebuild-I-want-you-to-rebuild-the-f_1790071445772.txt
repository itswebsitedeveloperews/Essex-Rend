# 12. Form Functionality

The form must actually work after the website is deployed to Cloudflare.

Implement a secure Cloudflare-compatible server-side endpoint for the form.

Requirements:

* POST submission only
* Server-side validation
* Required field validation
* Validate email address
* Sanitize inputs
* Reject obviously invalid submissions
* Basic rate limiting/spam protection where practical
* Cloudflare Turnstile support
* Never expose API keys in client-side JavaScript
* Display a proper loading state
* Display a success message
* Display useful error messages
* Disable duplicate submissions while sending

Send enquiries to:

[info@essexrend.co.uk](mailto:info@essexrend.co.uk)

Use environment variables for email credentials.

A service such as Resend can be used for transactional email.

Example environment variables:

```text
RESEND_API_KEY=
CONTACT_TO_EMAIL=info@essexrend.co.uk
CONTACT_FROM_EMAIL=
TURNSTILE_SECRET_KEY=
PUBLIC_TURNSTILE_SITE_KEY=
```

Do not commit secrets to GitHub.

If email credentials have not yet been provided, fully build the endpoint and form so credentials can simply be added later.
